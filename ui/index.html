🏷️ Transparency services for AI models – What's this?

This platform hosts several services that help report the capabilities, limits, risks, and repercussionsof different AI models. It allows model creators or third-party scientists to share descriptions of models in atransparent repository that can be indexed and disseminated. The descriptions are provided as model cards, which require registration to create. However, anyone can search for and access these cards using the search bar — simply type model names or keywords from the evaluation methodology.

👥 For the general public

The general public is free to browse through available model cards and use them as reference material to understand the strengths and weaknesses of AI models used in specific services or sectors. The platform also provides AI assistants to help card creators refine descriptions so that they are easily understood.

🧑‍💻 For model creators

Model creators are assisted by agents that help autocomplete, refine, and simplify model descriptions. Autocompletion leverages existing documentation (like PDFs or README files). Use the AICard Python library to programmatically manage cards via your credentials. This library can be added in model training and validation pipelines to automate the description of resources, datasets, and experiments, and compute a comprehensive suite of evaluation metrics. This website can also be hosted locally by following the instructions in the same AICard library page.
