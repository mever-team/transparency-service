✍️⚙️ Services for scientists

Register to share descriptions of models by you or others. LLM agents help refine or simplify text, or fill info from documentation (PDFs or READMEs, etc).

The AICard Python library can compute and programmatically submit model evaluations. It can also host this website locally.
